# SCP Union2.1 Supernova Cosmology Analysis

Аналіз даних наднових типу Ia з каталогу SCP Union2.1 для дослідження космологічних моделей.

## Основні можливості
- Завантаження та обробка даних Union2.1
- Перетворення distance modulus на світлову відстань \(D_L\)
- Порівняння спостережень із теоретичними моделями ΛCDM для різних значень \(\Omega_M\)
- Оцінка віку Всесвіту в плоскій космологічній моделі

## Залежності
- Python 3.x
- NumPy
- Matplotlib
- SciPy

Install with:
```bash
pip install numpy scipy matplotlib
```

## Використання
Просто запустіть скрипт — він автоматично завантажить дані з файлу `SCPUnion2.1_mu_vs_z.txt`, побудує графік \(D_L\) vs \(z\) (через швидкість) та виведе оцінки віку Всесвіту для \(\Omega_M = 0.01, 0.27, 0.99\).

> **Примітка**: перетворення червоного зсуву на швидкість використовує релятивістську формулу, що коректно лише для малих \(z\). Для повного космологічного аналізу рекомендується працювати безпосередньо з \(z\).

Start:
```bash
python lifetime_universe.py
```
